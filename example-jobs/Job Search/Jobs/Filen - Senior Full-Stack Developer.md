- **Self-hosted:** Infrastructure entirely in Germany (not AWS/etc)

## Tech Stack
- **Frontend:** React (web), React Native (mobile)
- **Languages:** TypeScript (primary), Rust (new SDK), Go, Kotlin, Swift
- **State:** Zustand (global state), React Query/TanStack Query (server state)
- **Desktop:** Electron
- **Mobile:** React Native + native modules (Kotlin/Swift when needed)
- **Testing:** Vitest, Playwright, Maestro
- **SDKs:** TypeScript SDK (current), Rust SDK (in development, replacing TS)
- **API:** Building toward API v4

## Architecture Notes
- **Encryption:** AES 256-bit, client-side, zero-knowledge
- **Storage:** Sharded and distributed across German data centers
- **Redundancy:** Data redundancy built-in
- **2026 Roadmap:**
  - Rust SDK completion (replacing TS SDK as core)
  - Sync engine rewrite (better reliability/consistency)
  - API v4 (security + performance improvements)
  - "Filen Spaces" (new platform layer)
  - Business plans & family accounts (after v4)
