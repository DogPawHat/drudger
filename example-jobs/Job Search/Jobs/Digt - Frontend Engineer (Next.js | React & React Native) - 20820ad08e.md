# Digt - Frontend Engineer

## Company Overview
**Digt AG** is a Swiss scale-up revolutionizing e-commerce for over 5 years. They operate exclusive platforms for closed communities:
- **Brands for Employees** 
- **Brands for Students**
- **MyAXA Deals Platform**

**Partnership:** Run the majority of **Twint Superdeals** in partnership with Twint (major Swiss payment provider).

**Scale:**
- 80+ passionate team members across Europe
- Mid double-digit million turnover
- 70% average annual growth
- **SEF.Growth High Potential Label** (Swiss Economic Forum)

## The Role
Frontend Developer with strong Next.js/React expertise to own the customer-facing experience.

### Key Responsibilities
- Build modern, high-performing interfaces in **Next.js and React**
- Work on both external platforms AND internal ERP interfaces
- Implement responsive, accessible UIs
- Optimize for Core Web Vitals, speed, scalability
- TDD mindset, clean testable code
- Agile/scrum participation, peer reviews

### What Makes It Unique
You'll shape both **external customer-facing experiences** AND **internal tools** — end-to-end impact on what users see and the systems that power it.

### First Major Mission
Deliver the **most ambitious UX upgrade in company history** — a major milestone working closely with design and product teams.
